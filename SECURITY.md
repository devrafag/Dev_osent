# Seguridad

RAEV Guard es una herramienta defensiva educativa. No envía los logs a ningún
servicio: el procesamiento se realiza localmente.

No publiques registros que contengan contraseñas, tokens, cookies, datos
personales o direcciones internas sensibles. Conserva los informes con los
mismos controles de acceso que los logs originales.

Para comunicar una vulnerabilidad del programa, abre un aviso privado al
propietario del repositorio en lugar de publicar datos explotables.
